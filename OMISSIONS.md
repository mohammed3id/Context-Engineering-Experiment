
# Three Deliberate Omissions

### 1. Full Project Documentation
I deliberately excluded the complete project documentation
because it is too long to include in the rules file.
Instead, the AI agent can be directed to the relevant
documentation files when needed.

### 2. Temporary Development Tasks
I excluded temporary development tasks because they
change frequently and are not permanent instructions
for the AI agent.

### 3. Generic Programming Advice
I excluded general instructions such as "write clean code"
and "follow best practices" because these are common
expectations that AI models generally understand already.
Including them would make the rules file unnecessarily long.
